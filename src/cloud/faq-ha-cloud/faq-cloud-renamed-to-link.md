From December 2, 2026, Home Assistant Cloud is called Home Assistant Link. Only the name changes. Your subscription, account, and settings carry over with no action needed. Read why in the [announcement blog post](https://www.home-assistant.io/blog/2026/10/02/big-tech-ruined-the-cloud-so-were-renaming-ours/).

## What changes?

You'll see the name "Home Assistant Link" on our websites, in emails, and in Home Assistant 2026.12 and later.

## What stays the same?

- **Features.** Remote access, Alexa and Google Home, speech-to-text and text-to-speech, and off-site backups all work as before.
- **Your setup.** Existing backups, speech settings, webhooks, and automations need no changes.
- **Technical names.** Some integration and API names in Home Assistant still use "cloud", such as the `cloud:` entry in `configuration.yaml` and entity IDs like `stt.home_assistant_cloud`. This has no effect on how Link works.
- **Your account.** Sign in with the same email and password at [account.nabucasa.com](https://account.nabucasa.com).

## Do I need to update Home Assistant?

Updating is optional. Versions before 2026.12 keep the name "Home Assistant Cloud", and all features work as usual. Update to 2026.12 or later to see the new name.

Our help articles use the new name. If you're on an older version, you'll see **Home Assistant Cloud** wherever an article says **Home Assistant Link**.

## Where can I get help?

For questions about Link features, your subscription, billing, or account, [submit a request](/hc/en-us/requests/new). For general Home Assistant questions, visit the [community forum](https://community.home-assistant.io) or the [Home Assistant Discord](https://www.home-assistant.io/join-chat).
